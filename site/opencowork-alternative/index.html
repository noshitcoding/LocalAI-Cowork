Compare open cowork projects without confusing their versions

Release channels: V2 2.0.0-alpha.8 is being prepared and is not published yet. The existing public V1 release is v0.3.1. These are separate applications and data profiles. Read the V2 preview scope.

Start with the project identity

LocalAI Cowork is an independent project. Similar names do not establish shared maintainers, code, security properties or release channels. Check the repository owner, license and exact release tag before following an installation guide.

Compare the workflow you need

  • Can you choose the model endpoint and see which context is sent?
  • Are file permissions and tool approvals explicit?
  • Does the exact package support your operating system and native dependencies?
  • Can you inspect the source revision, checksums and package acceptance results?
  • Are remote execution, recovery and mobile support actually accepted for that version?

V2 has a separate preview scope

LocalAI Cowork V2 is being prepared as a desktop preview. Managed runtime and full automation are still bounded experimental areas. The existing public V1 v0.3.1 release remains a separate application.
