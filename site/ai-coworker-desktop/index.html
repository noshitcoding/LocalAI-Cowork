V2 evaluation guide // Updated 9 November 2026

An open-source AI coworker desktop workspace — V2

Release channels: V2 2.0.0-alpha.8 is being prepared and is not published yet. The existing public V1 release is v0.3.1. These are separate applications and data profiles. Read the V2 preview scope.

A visible working loop

Choose the project, model, context and allowed tools. Review the prepared execution plan, follow the run, answer explicit review steps and inspect the result. The shared web interface and Rust core are used by the V2 desktop workspace.

Reusable workflows

The source includes typed inputs, explicit result connections, conditions, branches, relative waits, copied subworkflows and human review forms. Complete invoice processing, absolute deadlines and event waiting remain in development. A successful source-level workflow check does not qualify every installed model or backend.

Documents and knowledge

Guided document selection connects an inspected file and its hash. Optional document engines add supported read/write/OCR actions. Project and personal knowledge use notes, imports, topic folders and source/tag graphs; automatic semantic extraction remains open.
