AppImage provides the broadest coverage across glibc-based desktop distributions. DEB and RPM packages integrate with the two most common native package families.

Download AppImage Download DEB Download RPM

AppImage: widest distribution coverage

Use the AppImage on Arch, Manjaro, Gentoo, or another glibc-based desktop distribution when no native package is available. Make the download executable with chmod +x LocalAI-Cowork-x86_64.AppImage, then run it. The signed in-app updater uses this format.

DEB: Debian family

Install on Debian, Ubuntu, Linux Mint, and related distributions with sudo apt install ./LocalAI-Cowork-x86_64.deb.

RPM: Fedora and openSUSE families

Install with sudo dnf install ./LocalAI-Cowork-x86_64.rpm or, on openSUSE, sudo zypper install ./LocalAI-Cowork-x86_64.rpm.

Compatibility boundary

Releases are built on Ubuntu 22.04 for a conservative glibc baseline and require GTK 3 plus WebKitGTK 4.1. No single glibc desktop binary can promise literal compatibility with every Linux distribution. ARM64 and musl-only systems such as Alpine are not release targets yet.

Crew workflows and current limits

Crew workflows require Python 3.10 through 3.13 on Linux and create an isolated environment during first initialization. Native Windows sandboxing, Windows Credential Manager integration, Windows Office automation, and the bundled Windows PDFium library are not available. The core workspace, Ollama route, files, MCP tools, terminal, and tasks remain Linux release targets.
