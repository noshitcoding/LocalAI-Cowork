V2 evaluation guide // Updated 9 November 2026

Open-source AI cowork — source, packages and release evidence

Release channels: V2 2.0.0-alpha.8 is being prepared and is not published yet. The existing public V1 release is v0.3.1. These are separate applications and data profiles. Read the V2 preview scope.

Inspect a precise version

The project is Apache-2.0 software. The public V1 repository and releases retain their history; V2 development and its future preview must be tied to an explicit version and release revision. Until V2 is published, the public default branch and latest-release link are not a promise that you are reading V2 sources.

Source is one part of a release

Review the exact release notes, source revision, dependency lockfiles, package checksums and software bill of materials. Tests apply to the bytes and scope named in their reports. A historic green report is not proof for a later installer.

Modify and operate deliberately

Model endpoints, MCP servers and document engines have their own dependencies, permissions and data routes. Source access makes these decisions inspectable; it does not remove deployment, credential management or package acceptance work.
