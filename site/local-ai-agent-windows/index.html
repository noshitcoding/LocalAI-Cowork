V2 evaluation guide // Updated 9 November 2026

A local AI workspace for Windows — V2 preview

Release channels: V2 2.0.0-alpha.8 is being prepared and is not published yet. The existing public V1 release is v0.3.1. These are separate applications and data profiles. Read the V2 preview scope.

Windows package and profile

V2 targets a current-user Windows x64 NSIS installer with a distinct preview application identity. The installed package must pass startup, tool approval, file import/download, stop and restart checks. Previous V1 installer results do not qualify V2.

Begin with one small task

  1. After publication, install the versioned V2 preview package and keep V1 available.
  2. Select the local sidecar or a compatible V2 server, then configure Ollama or your intended hosted endpoint.
  3. Work on a copy of a non-sensitive folder. Review the execution plan and any requested tool permission.
  4. Inspect resulting files and verify that the state survives a normal restart.

Platform limits

Managed execution and Windows/Office automation require separate runtime setup and acceptance. Document-engine path preflight is available in source; full Windows long-path support remains open. An Android application and an automatic V1-to-V2 upgrade are outside this desktop preview.
