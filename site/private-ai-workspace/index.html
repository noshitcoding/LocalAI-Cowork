V2 evaluation guide // Updated 9 November 2026

A private AI workspace with explicit data boundaries

Release channels: V2 2.0.0-alpha.8 is being prepared and is not published yet. The existing public V1 release is v0.3.1. These are separate applications and data profiles. Read the V2 preview scope.

Identify where the workspace runs

V2 lets a personal workspace select its local desktop sidecar or a compatible self-hosted V2 server. The selected backend determines where application state and run records are stored. Preview profiles are separate from V1 databases.

Follow each data route

ConfigurationData boundary
Ollama on the same deviceInference requests can remain local, subject to model and tool configuration.
Hosted model or remote V2 serverRequests and selected context reach that configured service.
MCP, browser, terminal or document engineThe tool's permissions and network behavior determine its access.
Project websiteStatic pages ship no analytics, advertising code, trackers or third-party fonts. GitHub Pages has its own request logging.

Evaluate using selected copies

Start with non-sensitive files, grant only the needed folder/tool access and inspect the plan and resulting artifacts. Credential storage depends on the selected platform/backend; use its configuration and security documentation. Do not assume a remote service inherits local storage guarantees.

Read the privacy notice before adding a model endpoint or tool.
