Considering an open-source Claude Cowork alternative

Release channels: V2 2.0.0-alpha.8 is being prepared and is not published yet. The existing public V1 release is v0.3.1. These are separate applications and data profiles. Read the V2 preview scope.

Choose the workflow you actually need

If you are evaluating an alternative to Claude Cowork, test the files, tools and review steps you intend to use. LocalAI Cowork is an independent Apache-2.0 workspace. Its V2 preview is being prepared with local Ollama and configurable hosted endpoints, selected context, execution plans and explicit approvals.
