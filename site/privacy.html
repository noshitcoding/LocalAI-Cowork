Privacy

Short version: the project website contains no analytics or advertising code. V1 and the V2 preview use separate profiles. V2 can use a local desktop sidecar or a compatible self-hosted server; the selected backend and tools determine where information is processed.

Project website

This static site does not set its own cookies, create user accounts, load third-party fonts, or include analytics, advertising, pixels, or session-replay scripts. It is hosted by GitHub Pages. GitHub may process technical request data such as IP addresses and browser information under the GitHub Privacy Statement.

Desktop app data

With the local desktop sidecar, application state, run history and selected workspace context are stored on that device. If you choose a compatible self-hosted V2 server, the configured server stores the corresponding state. Optional identity, sharing and synchronization capabilities require their own configured services and permissions. The project website does not provide a hosted app account or synchronization service.

V2 2.0.0-alpha.8 is being prepared and is not published yet. Read the preview scope. Existing public downloads contain V1 v0.3.1.

Model providers and connected tools

When you choose a remote model provider, connector, MCP server, webhook, or web-enabled tool, the app sends the information required to perform your requested action to that endpoint. The recipient and its privacy terms depend on the endpoint you configure. Ollama can be used locally to avoid sending model prompts to a hosted provider.

Credentials

Credential storage depends on the selected platform, backend and configured secret provider. The V2 local sidecar and self-hosted server have separate key and credential requirements. Use the security and setup documentation matching the exact package; do not assume a remote service has the same credential boundary as a local desktop profile.

Website tracking and diagnostics

This static website ships no telemetry sender or analytics scripts. App diagnostics, support exports and third-party service logging are separate from the website; inspect the settings and release documentation of the exact app version before sharing diagnostic information.

Local permissions

LocalAI Cowork can work with local files, terminals, processes, and connected tools. These capabilities are powerful. Review workspace access, permission settings, approval prompts, and third-party configurations before using the app with sensitive material.

Security reports

Do not publish credentials or sensitive data in a public issue. Report security vulnerabilities privately through GitHub Security Advisories.

Questions

For non-sensitive privacy questions, open a privacy question. This notice describes the open-source project and is not a substitute for the terms of any model provider or service you connect.
