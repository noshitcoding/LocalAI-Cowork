V2 evaluation guide // Updated 9 November 2026

Ollama in LocalAI Cowork V2

Release channels: V2 2.0.0-alpha.8 is being prepared and is not published yet. The existing public V1 release is v0.3.1. These are separate applications and data profiles. Read the V2 preview scope.

Choose the endpoint deliberately

The V2 model configuration supports Ollama and compatible hosted endpoints. Install and operate Ollama separately, make the intended model available, then configure its endpoint in the workspace. A reachable endpoint on another machine is a remote service even when it uses Ollama.

Evaluate model and tool behavior separately

Begin with a short chat, then one permitted tool action on a copy of test files. A model's ability to produce text does not establish reliable tool calling, structured extraction or a complete workflow. Hardware requirements depend on the model you choose.

Local inference and network access

Using a model on the same device can keep inference requests local. MCP processes, browser actions, web tools, document engines or a selected server can still use the network according to their configuration and permissions.
