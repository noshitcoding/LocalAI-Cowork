# LocalAI Cowork v0.3.11 private development snapshot

## Summary

v0.3.11 fixes OpenRouter Crew profile handling after an application reinstall or restart. Securely stored API keys remain outside renderer state and are now recognized through their credential-presence marker.

## Changes

- Crew diagnostics accept a securely stored API key even when the renderer-side plaintext field is intentionally empty.
- Crew model discovery passes the selected profile ID to the native credential resolver.
- Immediate Crew runs, task-triggered runs, scheduled runs, and resumed runs use the Crew-selected API profile instead of silently reverting to the global default.
- A deleted Crew-selected profile is reported as unavailable instead of being replaced without notice.

## Compatibility and data handling

No database schema or externally documented API changes are introduced. Existing API keys stay in the operating-system credential store and are not copied into renderer persistence, logs, or Crew snapshots.
