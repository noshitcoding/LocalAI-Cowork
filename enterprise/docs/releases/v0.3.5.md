# LocalAI Cowork v0.3.5 private development snapshot

Status: private development build; not a published GitHub Release.

v0.3.5 keeps the main menu available while users navigate and restores direct control over every crew member and model selection.

## Highlights

- **Persistent, non-modal main menu:** Main routes, subsections, search results, commands, context, and project actions keep the burger menu open. The workspace remains undimmed and interactive while the menu is open; only the visible close button closes it and restores focus to the burger button.
- **Direct crew participation controls:** Every available crew member has an always-visible active/inactive switch. Disabling a member is reversible and preserves model, backend, tools, personality profile, and task assignments.
- **Crew-local model controls:** Expanded members can keep an individual API/Codex backend and model override without modifying their linked global personality profile.
- **One model for the whole crew:** The Crew members section exposes the crew model selector and an apply-to-all action. Applying it includes inactive members and resets individual backend and model pins to crew inheritance.
- **Configured API profiles stay selectable:** The crew provider selector recognizes the global API profile across Ollama, OpenRouter, OpenAI, and custom compatible profiles, and falls back to the first configured endpoint when an old default reference is no longer valid.

## Compatibility and migration

No data migration or external API change is required. Existing crews and personality profiles remain compatible, and profile synchronization continues to retain all available members.

## Private build integrity

- Source branch: `codex/internal-development-v0.3.5` on the private internal remote
- Windows artifact: locally built `LocalAI-Cowork-Setup.exe`
- The local development installer is not Authenticode-signed and may display “Unknown publisher.”
- This snapshot must not create a public tag, GitHub Release, updater manifest, or public package.

## Known limitation

At compact window widths, the open menu overlays the left portion of the workspace instead of resizing it.
