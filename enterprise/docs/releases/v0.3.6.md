# LocalAI Cowork v0.3.6 private development snapshot

Status: private development build; not a published GitHub Release.

v0.3.6 restores direct access to task chats from the normal workspace sidebar.

## Highlights

- **Task chats back in the sidebar:** A separate collapsible Tasks group lists every task with its current status and opens the associated task chat directly.
- **Clear separation:** Task threads remain separate from ordinary chats while staying available beside projects and chats.
- **Task-aware chat restoration:** Opening a task preserves its runner, crew, backend selection, working folder, and persisted conversation when available.

## Compatibility and migration

No data migration or external API change is required. Existing tasks and their linked chat threads remain compatible.

## Private build integrity

- Source branch: `codex/internal-development-v0.3.6` on the private internal remote
- Windows artifact: locally built `LocalAI-Cowork-Setup.exe`
- The local development installer is not Authenticode-signed and may display "Unknown publisher."
- This snapshot must not create a public tag, GitHub Release, updater manifest, or public package.

## Known limitation

At compact window widths, the open menu overlays the left portion of the workspace instead of resizing it.
