# LocalAI Cowork v0.3.10 private development snapshot

Status: private development build; not a published GitHub Release.

v0.3.10 makes Crew model selections durable across application restarts and partial daemon reconciliation failures.

## Highlights

- **Saved Crew models survive restarts:** A newer locally selected Crew model is no longer replaced by stale daemon metadata during startup.
- **Early durable mirroring:** Crew and provider change tracking is installed before fallible reconciliation work, so an unrelated startup-sync failure cannot disable later writes.
- **Comparable Crew revisions:** Crew definitions now carry their `updatedAt` timestamp into the local daemon. Legacy daemon entries without a timestamp are repaired once from the persisted local Crew state.

## Compatibility and migration

No database schema or externally documented API changes are introduced. On the first v0.3.10 startup, an existing legacy Crew entity without `updatedAt` preserves the locally persisted Crew definition and is mirrored back to the daemon with a timestamp. Existing Crew IDs, agents, tasks, provider selections, and credentials remain unchanged.

## Verification target

Change the model for an existing Crew, restart LocalAI Cowork, and confirm that the selected model remains active. The daemon Crew entity must contain the same model and an `updatedAt` timestamp after reconciliation.
