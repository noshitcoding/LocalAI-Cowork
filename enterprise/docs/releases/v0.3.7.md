# LocalAI Cowork v0.3.7 private development snapshot

Status: private development build; not a published GitHub Release.

v0.3.7 hardens OpenRouter crew execution, event recovery, provider timeouts, and API profile persistence.

## Highlights

- **Reliable crew responses:** Crew runtime results use a dedicated framed response, while unrelated console output can no longer corrupt an otherwise valid result.
- **Complete live monitor recovery:** Paginated runtime events are loaded serially, deduplicated by sequence, and fully processed before a completed run is finalized.
- **Safer API profile lifecycle:** Deleted seeded profiles remain retired across restarts, credential state is restored from secure storage, and replacement profiles are not overwritten by defaults.
- **Bounded provider timeouts:** Model-specific request timeouts are normalized to the local daemon's supported maximum.

## Compatibility and migration

The internal crew wire protocol adds the `crew_response` frame while retaining support for legacy unframed responses. Database schema version 28 adds retirement metadata for API profiles; existing profiles are migrated automatically. There is no externally documented API change.

- Source branch: `codex/internal-development-v0.3.7` on the private internal remote

- This snapshot must not create a public tag, GitHub Release, updater manifest, or public package.

## Verification target

An OpenRouter crew run completes with its task result, the live monitor catches up to more than zero events, and unrelated runtime output does not produce an `invalid JSON` failure.
