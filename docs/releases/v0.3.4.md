# LocalAI Cowork v0.3.4

v0.3.4 fixes persistent local runs and restores Codex compatibility for fresh installs and upgrades from v0.3.1 through v0.3.3.

## Highlights

- **Persistent runs validate correctly:** New installations create a stable RFC 4122 v4 user ID instead of the legacy all-zero-version placeholder rejected by the desktop contract.
- **Existing data is repaired automatically:** On daemon startup, affected run records are migrated to the installation's persistent user ID before the app reads them.
- **Codex works with the bundled runtime:** Thread and turn requests use the approval and sandbox values accepted by the pinned Codex App Server (`untrusted`, `read-only`, and `workspace-write`).
- **Installer regression coverage:** The installed-payload smoke test now checks the daemon's persisted identity and authenticated health response.

## Root causes fixed

The local daemon serialized `creator_user_id` as `00000000-0000-0000-0000-000000000001`. Rust accepted that value, but the frontend UUID contract rejected it because the UUID has no valid version or RFC variant. Every persistent model path passed through the same run parser, so Codex, OpenRouter, Ollama, and other OpenAI-compatible providers appeared to fail in the same way.

The bundled Codex runtime also removed the legacy `unlessTrusted` approval variant and camel-case thread sandbox names. v0.3.4 pins the request values used by the installed runtime and adds regression coverage for both protocol contracts.

## Installation and update integrity

- Windows: `LocalAI-Cowork-Setup-x64.exe`
- Linux: AppImage, DEB, and RPM packages
- In-app updates: signed Tauri updater artifacts and `latest.json`
- Verification: `SHA256SUMS`, CycloneDX SBOM, third-party notices, provenance, and GitHub attestations

> **Windows publisher notice:** Unless Authenticode credentials are configured for the release workflow, Windows may display "Unknown publisher." Verify `SHA256SUMS` and the GitHub artifact attestations before running the installer. In-app updater artifacts are independently protected by the mandatory Tauri updater signature.
