# LocalAI Cowork v0.3.4

v0.3.4 fixes repeated Windows console windows when sending prompts through the bundled Codex runtime.

## Highlights

- **Persistent Codex runtime:** The local daemon now reuses one Codex App Server per profile instead of starting a new process for every prompt.
- **Safe recovery:** Canceled, timed-out, failed, or exited Codex sessions are discarded and started cleanly on the next run.
- **Profile isolation:** Concurrent runs are serialized per Codex profile without blocking independent profiles.
- **Bounded diagnostics:** Long-running Codex sessions retain only a bounded tail of stderr output.

## Installation and update integrity

- Windows: `LocalAI-Cowork-Setup-x64.exe`
- Linux: AppImage, DEB, and RPM packages
- In-app updates: signed Tauri updater artifacts and `latest.json`
- Verification: `SHA256SUMS`, CycloneDX SBOM, third-party notices, provenance, and GitHub attestations

> Windows publisher notice: Local development installers are not Authenticode-signed and may display “Unknown publisher.” Published artifacts must be verified with `SHA256SUMS` and the GitHub artifact attestations.

## Known limitation

The first Codex request after an app or daemon restart still performs one-time runtime and repository initialization. The repeated process startup on every subsequent prompt is removed.
