# Support

Search [existing issues](https://github.com/noshitcoding/LocalAI-Cowork/issues)
and read the notes for the exact installed release before reporting a problem.
Specify V2 desktop/web, configured V2 server, Enterprise or historical V1; include
the version, platform, installation method and minimal reproducible workflow.

- [Bug report](https://github.com/noshitcoding/LocalAI-Cowork/issues/new?template=bug_report.yml)
- [Feature request](https://github.com/noshitcoding/LocalAI-Cowork/issues/new?template=feature_request.yml)
- [Privacy question](https://github.com/noshitcoding/LocalAI-Cowork/issues/new?template=privacy_question.yml)
- [Private security report](SECURITY.md)

Remove tokens, keys, passwords, cookies, private files/folders, network addresses
and account identifiers before sharing logs or screenshots. Use synthetic data.
Do not upload private development evidence or operator profiles.
